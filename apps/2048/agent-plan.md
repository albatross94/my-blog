# Plan 서브에이전트 지침 — 2048 게임

## 역할
2048 웹앱의 **구현 계획서**만 작성한다. 코드는 작성하지 않는다.

## 요구사항 (사용자 요청)
- 방향키로 숫자 타일을 밀어서 같은 숫자끼리 합치는 2048 퍼즐 게임
- 점수판 포함 (현재 점수 + 최고 점수, 최고 점수는 localStorage 저장)

## 제약 (CLAUDE.md)
- HTML / CSS / JavaScript만 사용. 외부 라이브러리 최소화 (CDN 허용, 가급적 사용 안 함)
- `/apps/2048/` 폴더 안에서 자체 완결. 블로그의 다른 파일은 건드리지 않는다
- 모바일에서도 사용 가능해야 함 (터치 스와이프 지원 고려)

## 수정 가능 범위
- 생성할 파일: `C:\Users\albat\OneDrive\Desktop\my-blog\apps\2048\spec.md` 한 개만
- 그 외 파일은 읽기만 가능, 수정 금지

## spec.md에 포함할 내용
1. 앱 개요와 기능 목록 (이동/합치기 규칙, 새 타일 생성, 점수, 최고 점수, 게임오버/승리 판정, 새 게임 버튼)
2. 입력 방식 (방향키, 터치 스와이프, 필요 시 WASD)
3. 파일 구조 (index.html, style.css, game.js 등) 와 각 파일 역할
4. 핵심 로직 설계 (보드 표현, 한 줄 슬라이드·병합 알고리즘, 이동 불가 판정)
5. UI/디자인 (타일 색상, 반응형, 다크 모드 여부, 애니메이션 수준)
6. 검증 체크리스트 (Review 단계에서 사용)

간결하게, 2페이지 이내로 작성한다.
