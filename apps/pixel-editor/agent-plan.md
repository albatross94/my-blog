# Plan 서브에이전트 지침 — 픽셀 아트 에디터

## 역할
픽셀 아트 에디터 웹앱의 **구현 계획서**만 작성한다. 코드는 작성하지 않는다.

## 요구사항 (사용자 요청)
- 16×16 격자에 도트를 찍어 그림을 그린다
- 완성하면 PNG로 저장(다운로드)할 수 있다
- 색상 팔레트를 넣는다

## 제약 (CLAUDE.md)
- HTML / CSS / JavaScript만 사용. 외부 라이브러리 최소화 (CDN 허용, 가급적 사용 안 함)
- `/apps/pixel-editor/` 폴더 안에서 자체 완결. 블로그의 다른 파일은 건드리지 않는다
- 모바일에서도 사용 가능해야 함 (터치로 그리기 지원 고려)

## 수정 가능 범위
- 생성할 파일: `C:\Users\albat\OneDrive\Desktop\my-blog\apps\pixel-editor\spec.md` 한 개만
- 그 외 파일은 읽기만 가능, 수정 금지. 참고용으로 `apps/2048/spec.md`와 코드 스타일을 읽어도 된다.

## spec.md에 포함할 내용
1. 앱 개요와 기능 목록 (그리기, 지우기, 색상 선택, 전체 지우기, PNG 저장 등 최소 범위. 과한 기능은 제외)
2. 입력 방식 (마우스 클릭·드래그, 터치 드래그. Pointer Events 사용 검토)
3. 팔레트 설계 (색상 개수와 구성, 현재 색 표시, 선택 상태 표시)
4. PNG 저장 방식 (canvas로 렌더링, 확대 배율(예: 16배 = 256×256) 및 격자선 미포함, 투명 배경 처리, 파일명)
5. 파일 구조 (index.html, style.css, 로직/UI 분리 여부)와 각 파일 역할
6. UI/디자인 (모바일 우선 반응형, 터치 대상 44px, 다크 모드 대응, 격자 표시)
7. 검증 체크리스트 (Review 단계에서 사용. PNG 저장 결과 확인 방법 포함)

간결하게, 2페이지 이내로 작성한다.
