# 픽셀 아트 에디터 구현 계획서 (spec)

## 1. 앱 개요와 기능 목록
16x16 격자에 도트를 찍어 그림을 그리고 PNG로 저장하는 웹앱. `/apps/pixel-editor/` 안에서 자체 완결(블로그 다른 파일 미수정), 외부 라이브러리·CDN 없음.

- **그리기**: 셀을 클릭/드래그하면 현재 색으로 칠함.
- **지우기**: 지우개 도구로 셀을 투명(빈 칸)으로 되돌림.
- **색상 선택**: 팔레트에서 현재 색 선택.
- **전체 지우기**: 모든 셀 초기화 (실수 방지를 위해 `confirm` 1회).
- **PNG 저장**: 버튼 한 번으로 다운로드.
- 제외: 실행 취소, 채우기, 레이어, 격자 크기 변경, 작업 저장/불러오기 (최소 범위 유지).

## 2. 입력 방식
- **Pointer Events** 사용 (마우스·터치·펜 통합). 격자 요소에 `pointerdown` / `pointermove` / `pointerup` / `pointercancel`.
- `pointerdown`에서 `setPointerCapture`, 그리기 시작. 이동 중에는 `document.elementFromPoint` 대신 격자 영역 좌표로 셀 인덱스를 계산(`floor((x - left) / cellSize)`)해 격자 밖은 무시.
- 드래그 중 건너뛴 셀이 없도록 이전 셀과 현재 셀 사이를 직선(Bresenham)으로 보간.
- 격자에 `touch-action: none`으로 터치 드래그 시 페이지 스크롤 방지. 우클릭 메뉴(`contextmenu`)는 격자에서 차단.
- 같은 셀에 같은 값이면 재렌더링 생략.

## 3. 팔레트 설계
- **16색 고정** (4x4 또는 8x2 그리드): 검정, 짙은 회색, 회색, 흰색, 빨강, 주황, 노랑, 연두, 초록, 청록, 하늘, 파랑, 보라, 분홍, 갈색, 살색. 별도 지우개 버튼은 팔레트 옆에 배치.
- **현재 색 표시**: 팔레트 위/옆에 현재 색 미리보기 칸 (지우개 선택 시 체크무늬 표시).
- **선택 상태**: 선택된 스와치에 두꺼운 외곽선(`--accent`) + `aria-pressed="true"`. 색에만 의존하지 않도록 테두리 두께로 구분.
- 스와치는 `<button>`, 크기 44px 이상, `aria-label`에 색 이름. 기본 선택은 검정.

## 4. PNG 저장 방식
- 데이터: `number|null[256]` 형태가 아닌 `string|null[16][16]` (CSS 색 문자열, null = 투명).
- 저장 시 **오프스크린 `<canvas>`**를 새로 만들어 렌더: 캔버스 16x16로 `fillRect(x, y, 1, 1)` 후 **16배 확대 256x256**으로 출력하거나, 256x256 캔버스에서 셀당 16x16 `fillRect`. 후자를 채택(`imageSmoothingEnabled = false` 불필요).
- **격자선 미포함**, 미칠한 셀은 **투명 배경** 유지(`fillRect` 호출 안 함, 배경색 채우지 않음).
- `canvas.toBlob(cb, "image/png")` -> `URL.createObjectURL` -> 임시 `<a download>` 클릭 -> `revokeObjectURL`.
- **파일명**: `pixel-art-YYYYMMDD-HHmmss.png`.

## 5. 파일 구조
```
apps/pixel-editor/
├── index.html   # 시맨틱 마크업: 헤더(제목), 격자 컨테이너, 팔레트, 도구 버튼(지우개/전체 지우기/PNG 저장). viewport meta, lang="ko"
├── style.css    # CSS 변수(색상), 격자·팔레트 레이아웃, 반응형, 다크 모드
├── editor.js    # 순수 로직 (DOM 비의존): 상태 grid, setCell, clear, line 보간, toPngCanvas 데이터 생성
├── ui.js        # 렌더링, Pointer Events 바인딩, 팔레트/버튼 이벤트, 다운로드 (ES module, editor.js import)
└── spec.md      # 본 문서
```
`index.html`은 `<script type="module" src="ui.js">`로 로드 (정적 서버로 확인). 격자는 CSS Grid 16x16의 `<div>` 셀 256개 또는 화면용 `<canvas>` 중 **CSS Grid 셀 방식** 채택(격자선·색 변수 처리 용이).

## 6. UI/디자인
- **모바일 우선**: 격자는 정사각형 `width: min(92vw, 28rem)`, 좌우 여백 16px 이상, 가로 스크롤 없음. 데스크톱 폭에서는 격자 옆에 도구 패널 배치(`min-width` 미디어 쿼리).
- **터치 대상**: 팔레트 스와치·도구 버튼 모두 44px 이상 (격자 셀은 드래그 대상이라 예외).
- **색상**: UI 색은 CSS 변수(`--bg`, `--fg`, `--border`, `--accent` 등). 팔레트 색 자체는 데이터 값이라 JS 상수로 정의.
- **다크 모드**: `prefers-color-scheme`로 변수 재정의. 캔버스(그림) 영역 배경은 체크무늬로 투명을 표현해 양 테마에서 구분 가능하게 함. 수동 토글은 범위 외.
- **격자 표시**: 셀 사이 얇은 구분선(`--border`), 화면에서만 표시, PNG에는 미반영.
- **접근성**: 버튼 `aria-label`, 포커스 표시 유지, `prefers-reduced-motion` 불필요한 애니메이션 없음.

## 7. 검증 체크리스트 (Review용)
- [ ] 16x16 격자 표시, 클릭 시 해당 셀만 현재 색으로 칠해짐
- [ ] 마우스 드래그로 연속 그리기, 빠르게 움직여도 끊김 없음 (보간)
- [ ] 터치 드래그로 그리기 동작, 격자 위 드래그 시 페이지 스크롤 안 됨 (모바일/에뮬레이션)
- [ ] 격자 밖으로 드래그해도 오류 없음, 포인터를 떼면 그리기 종료
- [ ] 지우개로 셀이 비워지고, 전체 지우기 시 모든 셀 초기화
- [ ] 16색 팔레트 선택 시 현재 색 표시와 선택 강조가 일치
- [ ] PNG 저장: 파일이 `pixel-art-날짜-시간.png`로 다운로드됨
- [ ] 저장된 PNG를 열어 확인: 크기 256x256, 격자선 없음, 미칠한 영역 투명(이미지 뷰어/브라우저 체크무늬 또는 어두운 배경에서 확인), 그린 도트 위치·색이 화면과 일치
- [ ] 빈 격자로 저장해도 오류 없이 완전 투명 PNG 생성
- [ ] 375px 폭 및 데스크톱에서 레이아웃 정상, 가로 스크롤 없음, 버튼 44px 이상
- [ ] 라이트/다크 양쪽에서 격자·팔레트·버튼 식별 가능
- [ ] 외부 라이브러리·CDN 미사용, 콘솔 에러 없음, `apps/pixel-editor/` 밖 파일 미수정
