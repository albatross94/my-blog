이 블로그는 프레임워크 없이 **HTML, CSS, JavaScript**만으로 만들었고, `posts/` 폴더의 마크다운 파일을 읽어 화면에 보여줍니다.

## 새 글 쓰는 법

1. `posts/` 폴더에 `my-post.md` 파일을 만든다.
2. 맨 위에 제목·날짜·태그를 적는다.
3. `posts/index.json`에 항목을 추가한다.

## 코드 블록

```js
const greet = (name) => `안녕하세요, ${name}!`;
console.log(greet('블로그'));
```

## 인용문

> 읽기 좋은 글은 읽기 좋은 화면에서 시작한다.
