클로드 코드로 블로그를 만들면서 웹의 세 가지 기본 기술이 각각 어떤 일을 하는지 감이 잡혔습니다. 한 줄로 요약하면 이렇습니다.

> HTML은 **뼈대**, CSS는 **옷차림**, JavaScript는 **움직임**입니다.

## HTML — 구조

페이지에 무엇이 있는지를 정의합니다. 제목, 본문, 목록, 링크 같은 내용의 뼈대입니다.

- `header`, `main`, `article`, `footer` 같은 시맨틱 태그로 의미를 담습니다.
- 이 블로그에서는 `index.html` 하나가 헤더와 본문 컨테이너를 가진 셸 역할을 합니다.

## CSS — 모양

같은 구조를 어떻게 보이게 할지 정합니다. 색, 글꼴, 여백, 배치가 여기에 속합니다.

- CSS 변수로 색을 한 곳에서 관리하면 다크 모드 전환이 쉬워집니다.
- 미디어 쿼리로 모바일과 데스크톱 화면에 맞게 레이아웃을 바꿉니다.

```css
:root[data-theme="dark"] {
  --bg: #111;
  --fg: #eee;
}
```

## JavaScript — 동작

페이지가 사용자와 상호작용하고 데이터를 다루게 합니다.

- `fetch`로 마크다운 파일을 불러옵니다.
- `marked`로 마크다운을 HTML로 바꿔 화면에 넣습니다.
- 해시 라우팅으로 목록과 글 화면을 오갑니다.
- 다크 모드 토글을 누르면 선택값을 저장합니다.

## 정리

| 기술 | 역할 | 이 블로그에서 |
| --- | --- | --- |
| HTML | 구조 | 페이지 셸, 시맨틱 태그 |
| CSS | 스타일 | 테마, 타이포그래피, 반응형 |
| JavaScript | 동작 | 글 불러오기, 라우팅, 테마 토글 |

세 기술이 각자의 역할에 집중할수록 코드가 깔끔해진다는 것을 배웠습니다.
